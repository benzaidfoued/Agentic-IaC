# Changelog

All notable changes are documented here. Versioning follows Semantic Versioning; 0.x minor
releases may change APIs, with migration notes. Security fixes should be backported to the
latest supported minor line where practical.

## 0.1.0 - Initial alpha

- Typed catalog requests with deterministic and optional LangChain modes.
- Terraform saved-plan workflow with approval binding and destructive-change checks.
- Crossplane v2 Azure XR example, Kubernetes dry-run, GitOps export and readiness observation.
- SQLite FTS5 grounding and a proposal-only stdio MCP server.
- CLI, tests, local demo, contribution/security documentation and GitHub release workflow.
